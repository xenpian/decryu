# DeCry

Electron-based UI clone and interactive desktop application.

## 🚀 Features

- Interactive ransomware-style UI simulation / desktop clone
- Wallpaper setter script integration (`set-wallpaper.ps1`)
- Built with Electron and vanilla web technologies (HTML, CSS, JS)

## 📦 Getting Started

### Installation

```bash
npm install
```

### Running the App

```bash
npm start
```

### Building Portable Executable

```bash
npm run build
```
